# Himnos y Cánticos — versión web para GitHub Pages

Esta carpeta ya es el sitio terminado. No necesita Flutter, Node, base de datos ni un servidor propio.

## Publicar el enlace

1. En GitHub, crea un repositorio público. Puede tener cualquier nombre.
2. Sube **todo el contenido de esta carpeta** a la rama `main`, conservando las carpetas `icons` y `documentacion`.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main`, la carpeta `/(root)` y pulsa **Save**.
6. Espera uno o dos minutos. GitHub mostrará el enlace publicado.

El enlace tendrá este formato:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

Todos los enlaces internos son relativos, por lo que el nombre del repositorio no está fijado.

## Usar en iPhone

1. Abre el enlace publicado en Safari.
2. Pulsa **Compartir**.
3. Elige **Añadir a pantalla de inicio**.
4. Abre el icono “Himnos” como una aplicación.

Las letras, favoritos, guardados, tema y playlists permanecen en ese navegador. Audio, video y partituras necesitan conexión porque se sirven desde el almacenamiento oficial.

## Actualizar más adelante

Sustituye los archivos del repositorio por la nueva versión. GitHub Pages publicará el cambio. Si el iPhone conserva una versión anterior, cierra y vuelve a abrir la aplicación web con conexión.

## Contenido incluido

- Inicio directo en **Himnos**, sin pantalla inicial intermedia.
- Catálogo y letras integrados en el sitio.
- Búsqueda por número, título y texto de la letra.
- Favoritos, recientes y letras guardadas.
- Audio, video y partituras mediante los enlaces oficiales.
- Escucha continua, aleatoria, repetición, cola y controles multimedia.
- Creación, edición y reproducción de playlists.
- Añadir a una playlist desde la lista de Himnos o desde Escucha.
- Apariencia configurable y tamaño de letra.
- PWA instalable en iPhone y Android.

## Límites propios de una página web

- iOS puede suspender una página si el sistema necesita memoria; al volver se conserva la información local, pero puede ser necesario reanudar el audio.
- Las playlists no se sincronizan entre teléfonos porque no existe una cuenta de usuario ni un servidor de datos.
- “Guardar letra” conserva la letra dentro de esta aplicación web; no descarga los archivos multimedia.
